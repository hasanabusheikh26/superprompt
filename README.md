# SuperPrompt Extension

A lightweight Chrome extension that enhances text using local AI processing. Highlight any text on a webpage, click the SuperPrompt icon, and get an enhanced version that you can edit and replace.

## 🚀 **Features**

- **Local AI Enhancement** - No API keys or external dependencies
- **Smart Prompt Engineering** - 6 enhancement types (Professional, Detailed, Concise, Friendly, Simple, Steps)
- **True Overlay Design** - Clean popup without background effects
- **Works Everywhere** - Compatible with all sites including ChatGPT
- **Privacy Focused** - No data sent to external servers

## 🛠️ **Installation**

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hasanabusheikh26/superprompt.git
   cd superprompt
   ```

2. **Load in Chrome:**
   - Open `chrome://extensions/`
   - Enable "Developer mode" (top right)
   - Click "Load unpacked"
   - Select the `extention` folder
   - Pin the extension to toolbar

## 🎯 **How to Use**

1. **Highlight text** on any webpage
2. **Click the SuperPrompt icon** that appears
3. **Add instructions** (optional) for specific enhancement
4. **Edit the enhanced text** if needed
5. **Click "Replace"** to update the original text
